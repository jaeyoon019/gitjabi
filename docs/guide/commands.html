먼저, 두 종류를 구분하세요

터미널에 치는 명령은 크게 두 종류입니다. 맨 앞에 git이 붙으면 Git 명령, 붙지 않으면 터미널 명령입니다.

터미널 명령

컴퓨터에게 하는 명령

폴더를 옮기고 파일을 만드는 것처럼 컴퓨터 자체를 다루는 명령입니다. Git과 상관없이 쓰이고, 운영체제에 따라 이름이 다를 수 있습니다.

cd ls touch cat open .

Git 명령

Git에게 하는 명령

변경을 기록하고 GitHub와 주고받는 명령입니다. 운영체제와 상관없이 맥과 Windows에서 똑같습니다.

git add git commit git push git pull

아래 표는 터미널 명령은 회색 머리, Git 명령은 주황색 머리로 구분했습니다.

A
터미널 명령git으로 시작하지 않는, 컴퓨터 자체의 명령

터미널 기본 명령

맥의 터미널과 Windows의 Git Bash에서 같이 쓰입니다. open .만 이름이 다릅니다. PowerShell이나 명령 프롬프트용 명령은 개인 작업 페이지의 Windows 섹션에 있습니다.

명령하는 일
pwd지금 있는 폴더의 위치를 보여 줍니다.
ls폴더 안 파일 목록을 보여 줍니다.
ls -a숨김 파일(.gitignore, .git 등)까지 보여 줍니다.
cd 폴더이름그 폴더 안으로 이동합니다.
cd ..한 단계 바깥 폴더로 나갑니다.
cd ~홈 폴더로 한 번에 이동합니다.
mkdir 폴더이름새 폴더를 만듭니다.
touch 파일이름빈 파일을 만듭니다.
echo "글" > 파일이름파일 내용을 그 글로 씁니다. 원래 내용은 지워집니다.주의
echo "글" >> 파일이름파일 끝에 한 줄 덧붙입니다.
cat 파일이름파일 내용을 화면에 출력합니다.
mv 이전이름 새이름파일 이름을 바꾸거나 다른 폴더로 옮깁니다.
cp 원본 복사본파일을 복사합니다.
rm 파일이름파일을 삭제합니다. 휴지통을 거치지 않아 되돌릴 수 없습니다.주의
rm -r 폴더이름폴더를 안의 파일과 함께 삭제합니다. 되돌릴 수 없습니다.주의
open .현재 폴더를 Finder로 엽니다. Windows(Git Bash)에서는 explorer .입니다.
clear터미널 화면을 깨끗하게 비웁니다.

키하는 일
Tab파일·폴더 이름 앞부분만 쓰고 누르면 나머지를 자동으로 채워 줍니다.
↑ / ↓이전에 친 명령을 다시 불러옵니다.
Ctrl + C실행 중인 명령을 중단합니다.

Git 명령모두 git으로 시작하는 명령

처음 설정

Git을 설치한 뒤 한 번만 하거나, 새 repo를 시작할 때 쓰는 명령입니다. 설치 방법은 설치 페이지를 참고하세요.

명령하는 일
git --versionGit이 설치되어 있는지 확인합니다. 버전 번호가 나오면 설치된 것입니다.
git config --global user.name "이름"commit에 남길 이름을 정합니다. 처음 한 번만 하면 됩니다.
git config --global user.email "메일주소"commit에 남길 이메일을 정합니다. GitHub 계정에 등록한 이메일을 쓰면 내 기록으로 연결됩니다.
git config --global pull.rebase falsepull할 때 합치는 방식을 merge로 고정합니다. divergent branches 안내가 더 이상 나오지 않습니다.
git config --list지금 설정을 모두 봅니다. 길면 q로 나옵니다.
git init지금 폴더를 새 Git 저장소로 만듭니다. 숨김 폴더 .git이 생깁니다.
git clone 주소GitHub의 repo를 내 컴퓨터로 통째로 복사합니다. 현재 폴더 안에 repo 이름의 폴더가 새로 생깁니다.
git remote -v내 저장소에 연결된 GitHub 주소를 확인합니다.
git remote add origin 주소내 저장소와 GitHub repo를 연결합니다. origin은 그 주소에 붙이는 이름입니다.

기본 작업

혼자 작업할 때 가장 자주 쓰는 명령입니다. 화면 읽는 법은 개인 작업 페이지에서 캡처와 함께 설명합니다.

명령하는 일
git status현재 상태를 보여 줍니다. 빨강은 add 전, 초록은 commit 대기입니다.
git add 파일이름그 파일을 스테이징에 올립니다.
git add -A바뀐 파일 전부(새 파일, 수정, 삭제)를 스테이징에 올립니다.
git add .현재 폴더 아래의 변경을 올립니다. repo 가장 바깥 폴더에서는 -A와 거의 같습니다.
git commit -m "메시지"스테이징에 있는 파일들을 기록으로 저장합니다.
git push내 commit을 GitHub에 올립니다.
git pullGitHub의 새 commit을 받아와 내 작업에 합칩니다.
git fetch받아오기만 하고 내 파일은 바꾸지 않습니다. pull은 fetch와 합치기를 한 번에 합니다.
git diffadd 하기 전 변경 내용을 줄 단위로 봅니다. q로 나옵니다.
git diff --stagedadd 해 둔 변경 내용을 줄 단위로 봅니다.
git logcommit 기록을 자세히 봅니다. q로 나옵니다.
git log --onelinecommit 기록을 한 줄씩 짧게 봅니다.

branch와 팀 작업

branch는 원래 기록(main)과 따로 작업하기 위한 갈래입니다. 작업을 합치는 Pull Request는 명령이 아니라 GitHub 화면에서 하는 작업입니다.

명령하는 일
git branchbranch 목록을 봅니다. *가 붙은 것이 지금 있는 branch입니다.
git branch 이름branch를 만듭니다. 이동은 하지 않습니다.
git switch 이름그 branch로 이동합니다.
git switch -c 이름branch를 만들고 바로 이동합니다.
git push -u origin 이름새로 만든 branch를 GitHub에 처음 올립니다. 그 뒤로는 git push만 쳐도 됩니다.
git merge 이름그 branch의 작업을 지금 있는 branch에 합칩니다.
git branch -d 이름합치기가 끝난 branch를 삭제합니다.
git stash아직 commit하지 않은 변경을 잠시 치워 둡니다. pull이 막힐 때 씁니다.
git stash pop치워 둔 변경을 다시 꺼냅니다.

명령이 막히거나 실수했을 때는 문제해결 페이지를 보세요.
