## 막혔던 곳

- **파일 업로드 단계**: GitHub에 로그인이 안 된 상태라 업로드 메뉴가 보이지 않았고, 실습 페이지에 "gitjabi-hello.txt를 찾지 못했어요"라는 메시지가 떴다. 로그인한 뒤 "uploading an existing file"로 파일을 올려서 해결했다.
- **명령어 붙여넣기**: 가이드의 명령어를 복사해서 Git Bash에 붙여넣었더니 `^[[200~` 같은 이상한 문자가 같이 들어가 `command not found`가 났다. 명령어를 직접 타이핑해서 해결했다.
- **`git push` 결과**: push했을 때 `Everything up-to-date`가 떠서 실패한 줄 알았다. 올릴 것이 더 없다는 뜻이고, GitHub 웹에서 파일이 올라간 것을 확인했다.
- **.gitignore 단계**: 실습 페이지가 파일을 찾지 못했다고 해서 `git status`로 상태를 먼저 확인했다. 빨간색은 add 전, ahead는 push 전이라는 것을 알게 됐다.
- **Pull Request 단계**: 터미널에서 push까지만 하고 완료를 눌렀더니 "PR을 찾지 못했어요"가 떴다. PR은 명령어가 아니라 GitHub 웹 화면에서 만들고 merge해야 했다. merge한 뒤 `git switch main`, `git pull`로 마무리했다.

## 튜토리얼에서 고쳤으면 하는 점

- 각 명령어가 무슨 뜻인지 짧은 설명이 있으면 좋겠다. 설명이 없어서 처음에는 순서대로 입력만 했고, 실습을 마친 뒤에야 add, commit, push의 흐름을 이해했다.
- 명령어를 붙여넣으면 이상한 문자가 들어갈 수 있으니 직접 타이핑하라는 안내가 있으면 좋겠다.
- `Everything up-to-date`처럼 오류처럼 보이지만 정상인 메시지의 뜻을 문제해결 페이지에 정리하면 좋겠다.

## 느낀 점

처음에는 GitHub에 대해 아무것도 몰라서 막막하고 어려워 보였다. 하지만 처음부터 하나씩 차근차근 따라 하다 보니 생각보다 어렵지 않았다. 다만 명령어는 가이드에 적힌 대로 입력했을 뿐 각각의 정확한 의미까지는 완전히 이해하지 못했다. 아직 팀 프로젝트를 해 본 적이 없어서 필요성을 크게 느끼지는 못했다. 그래도 팀 프로젝트를 하기 전에 이 사이트로 미리 연습해 보면 매우 유용할 것 같다는 생각이 들었다.
