# gitjabi

GitHub를 처음 쓰는 사람이 **직접 해 보며 배우는** 실습 튜토리얼과, 팀원들의 GitHub 사용 후기를 모은 저장소입니다.

## 왜 만들었나

GitHub는 협업에 자주 쓰는 중요한 도구인데, 사용법을 아는 학생은 많지 않습니다. 사용법과 사용 이유를 익혀 신입 개발자가 Git 활용에 어려움을 겪지 않게 하는 것이 목표입니다.

## 튜토리얼

**https://jaeyoon019.github.io/gitjabi/** (준비 중)

GitHub 아이디를 입력하고 안내대로 따라 하면, 페이지가 GitHub API로 결과를 확인해 다음 단계로 넘겨 줍니다.

1. 저장소 만들기
2. 파일 업로드
3. 웹에서 파일 만들기
4. 브랜치 만들기
5. Git 준비하기 (cmd)
6. 저장소 클론하기 (cmd)
7. 커밋하고 푸시하기 (cmd)

실습은 **본인 계정에 `gitjabi-practice` 저장소(Public)** 를 새로 만들어서 합니다. 이 저장소(`gitjabi`)에서 하지 않습니다.

## 저장소 구조

```
docs/      튜토리얼 웹페이지 (GitHub Pages로 배포)
reviews/   팀원 사용 후기 (한 사람당 파일 하나)
```

## 후기 올리는 법

전부 GitHub 웹 화면에서 할 수 있습니다.

1. 브랜치 드롭다운에서 `review/<GitHub 아이디>` 브랜치를 만든다
2. 그 브랜치에서 `reviews/TEMPLATE.md` 내용을 복사해 `reviews/<GitHub 아이디>.md`를 만들고 채운다
3. **Pull request**를 만든다 (`review/<아이디>` → `main`)
4. 다른 팀원 1명이 리뷰하고 승인하면 머지한다

튜토리얼에서 오류나 고칠 점을 발견하면 **Issues**에 올려 주세요.
